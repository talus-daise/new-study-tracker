# 学習ノート（Study Tracker）

Cloudflare Workers + D1 で動く、学習記録・日記・タスク管理アプリです。

- `/`（`index.html`）… 入力ページ。学習の記録・日記・タスク管理・持ち物チェック・
  固定学習ブロック・週次振り返りをまとめて操作します。
- `/display.html`… 表示ページ。タブレットでの常時表示を想定した1画面レイアウトで、
  月間カレンダー形式のストリークと「今日の学習」「今日の日記」の概要を表示します。

入力ページと表示ページはそれぞれ別のPWAとしてホーム画面に追加できます
（`manifest-input.json` / `manifest-display.json`）。

## 構成

```
study-tracker/
├── wrangler.toml       # Workers設定（D1・静的アセットのバインディング）
├── schema.sql          # D1のテーブル定義 + 初期学習タイプ（宿題/自学/通信）
├── src/index.js        # /api/* のAPIハンドラ（Workers本体）
└── public/
    ├── index.html      # 入力ページ
    ├── display.html    # 表示ページ
    ├── manifest-input.json
    ├── manifest-display.json
    ├── sw.js
    ├── css/style.css
    └── js/
        ├── input.js    # 学習記録・日記
        ├── tasks.js    # タスク管理・持ち物・固定学習ブロック・週次振り返り・集中モード
        └── display.js
```

## セットアップ

1. 依存関係のインストール（wrangler）
   ```
   npm install
   ```

2. Cloudflareにログイン
   ```
   npx wrangler login
   ```

3. D1データベースを作成
   ```
   npx wrangler d1 create study-tracker-db
   ```
   出力される `database_id` を `wrangler.toml` の
   `REPLACE_WITH_YOUR_DATABASE_ID` 部分に貼り付けてください。

4. スキーマを適用
   - ローカル動作確認用: `npm run db:init:local`
   - 本番用: `npm run db:init:remote`
   - 既存DBに対して再実行しても、新しく追加されたテーブル
     （`diary_entries` / `tasks` / `study_blocks` / `belongings` / `task_streak`）
     だけが安全に追加されます（`CREATE TABLE IF NOT EXISTS`）。

5. ローカルで確認
   ```
   npm run dev
   ```
   `http://localhost:8787/` が入力ページ、
   `http://localhost:8787/display.html` が表示ページです。

6. デプロイ
   ```
   npm run deploy
   ```

## 学習タイプについて

初期状態で「宿題」「自学」「通信」の3種類が登録されています（`schema.sql`）。
入力ページ下部の「学習タイプを編集する」から、名前と色を自由に追加・削除できます
（記録が残っているタイプは削除できません）。追加したタイプは表示ページの
カレンダーの色分け・凡例にも自動的に反映されます。

## テスト期間について

入力ページの「テスト期間を設定する」からテスト日（と任意の教科名メモ）を登録できます。

- テスト日の2週間前から前日までの14日間、毎日「テスト」タイプで記録すると、
  表示ページのカレンダーでそのテスト日が星マークと紫の縁取りでハイライトされます
  （テスト日そのものは記録が無くても構いません）。
- テスト日の14日前〜当日の期間中は、表示ページに「テスト期間限定連続学習」という
  専用のストリーク（通常のストリークとは別カウント）が表示されます。今日を含めて
  何日連続で「テスト」タイプの記録があるかを示し、テスト期間の外では表示されません。
- テスト期間に入る前でも、直近のテスト予定が「次のテスト：◯/◯ 教科名」として
  表示ページに小さく表示されます。
- 「テスト」という学習タイプは初期状態で登録済みです（`schema.sql`）。
  学習タイプ編集画面で別の名前に変えても、テスト期間判定用のフラグ（対策タイプ）は
  そのまま引き継がれます。

**既にデプロイ済みのDBにこの機能を追加する場合**は、`schema.sql`の再実行では
`is_test_type`列や`test_dates`テーブルは追加されません（`CREATE TABLE IF NOT EXISTS`
のため）。以下のマイグレーションを1回だけ実行してください。

```
npx wrangler d1 execute study-tracker-db --local  --file=migrations/0001_add_test_period.sql
npx wrangler d1 execute study-tracker-db --remote --file=migrations/0001_add_test_period.sql
```

新規にDBを作成する場合は`schema.sql`だけで、この機能を含むすべてのテーブルが揃います。

## 日記について

入力ページの「その日の日記」から、日付ごとに1件（上書き保存）で日記を記録できます。
表示ページの「今日の日記」に、今日書いた内容がそのままプレビュー表示されます。

## タスク管理について（task-managerから移植）

入力ページに以下の機能があります。

- **今日やること**：未完了タスクのうち、優先度スコア（種類の重要度 ÷ 締切までの残り日数。
  提出物 > 宿題 > 自由タスクの順、締切が近いほど・過ぎているほど優先度が上がる）が
  高い順に上位3件を表示します。前日から持ち越されたタスクは自動で「先延ばし回数」が
  加算されます。
- **集中モード**：「集中モードで進める」から、優先度が最も高いタスクだけを表示する
  全画面モードに入ります。完了すると自動で次のタスクに進み、3件完了するごとに
  「ひと息つこう」という小休止画面をはさみます。
- **持ち物チェック**：日付を指定して持ち物を登録し、チェックできます。その日の全項目に
  チェックが付くと達成ストリークが1日分加算されます。
- **固定学習ブロック**：曜日×時間帯で決まった学習時間を登録しておくと、その時間になった
  ときに「今日やること」欄にバナー通知が出ます（入力ページを開いている間のみ、
  30秒ごとにチェックします）。
- **週次振り返り**：過去7日間のタスク達成率・平均先延ばし回数・タスク達成ストリーク・
  種類別の完了数をまとめて表示します。
- タスク完了・持ち物全チェックで加算される「タスク達成ストリーク」は、学習記録の
  連続日数（表示ページのストリーク）とは別カウントです。

タスク管理・持ち物・固定学習ブロックは入力ページのみに実装しています
（表示ページは常時表示前提の1画面レイアウトのため、レイアウトを崩さないよう
今回は対象外にしています）。

## タスク管理と学習記録の連携

タスクの「完了」は、実際にどれだけ学習したかの記録につながるようにしています。

- **一覧の「完了」ボタン**：タップすると、記録するタイプ（宿題タスクなら「宿題」など、
  タスクの種類から推測した学習タイプを初期選択）と時間（初期値15分、±5分ボタンや
  直接入力で調整可）を確認するミニ画面が開きます。「記録して完了にする」で学習記録が
  同時に作られ、そのタスクに紐づきます。「記録せず完了にする」を選べば記録なしで
  完了だけできます。×で閉じれば完了自体を取り消せます。
- **集中モード**：タスクを表示している間、実際にかかった時間をストップウォッチのように
  計測します。「完了して次へ」を押すと計測時間が自動入力された記録確認画面が開き、
  保存すると学習記録として残ります。「中断」した場合も、1分以上経過していれば
  同じ画面で「中断した分だけ記録する」ことができます（タスク自体は完了になりません）。
- タスク一覧の各項目には、そのタスクに紐づく学習記録の合計時間が「📖 40分」のように
  表示されます。何度かに分けて取り組んだタスクでも、記録が積み上がっていくのがわかります。
- 学習記録の一覧（今日の学習・カレンダーの日別詳細）では、タスク完了時に記録された分に
  🔗マークが付きます。
- 週次振り返りに「今週の学習時間 合計」（うちタスク完了時の記録）を追加し、
  タスクの達成率と実際の学習時間を並べて振り返れるようにしています。

この連携により、`study_records`テーブルに`task_id`（任意・NULL可）が追加されています。
新規構築は`schema.sql`だけでOKですが、既にデプロイ済みのDBには以下のマイグレーションを
1回だけ実行してください。

```
npx wrangler d1 execute study-tracker-db --local  --file=migrations/0002_link_tasks_to_records.sql
npx wrangler d1 execute study-tracker-db --remote --file=migrations/0002_link_tasks_to_records.sql
```

## 表示ページの使い方

タブレットを横向きで壁や机に固定し、常時表示させる想定です。

- 左側：当月のカレンダー。各日付の下に、その日の学習内容を表す帯（バー）が付きます。
  目標学習時間（平日1時間30分／休日2時間）を100%とし、学習タイプごとの色で
  幅を割り振っているので、文字なしでも「その日どれくらい・何を学習したか」が
  一目でわかります。現在の連続記録（ストリーク）に含まれる日はオレンジの下線で
  つながって見えます。テスト日には📝マーク、条件を満たすと★マークが付きます。
- 日付をタップすると、その日の学習の内訳がポップアップで開きます
  （円グラフと、記録した学習の一覧）。
- 右側：現在の連続日数、今日記録した学習の一覧・合計時間（目標学習時間を100%とした
  円グラフ付き）、今日の日記のプレビュー。テスト期間中は専用のストリーク表示も加わります。
- 5分ごとに自動でデータを再取得するので、開きっぱなしでも最新の状態を保てます。
- カレンダーは「‹ ›」で前後の月に移動できます（今日の概要は常に「今日」を表示します）。
