# 学習ノート（Study Tracker）

Cloudflare Workers + D1 で動く、学習記録・日記・タスク管理アプリです。

- `/`（`index.html`）… 入力ページ。学習の記録・日記・タスク管理・持ち物チェック・
  固定学習ブロック・週次振り返りをまとめて操作します。
- `/display.html`… 表示ページ。タブレットでの常時表示を想定した1画面レイアウトで、
  月間カレンダー形式のストリークと「今日の学習」「今日の日記」の概要を表示します。

入力ページと表示ページはそれぞれ別のPWAとしてホーム画面に追加できます
（`manifest-input.json` / `manifest-display.json`）。

## 構成

```
study-tracker/
├── wrangler.toml       # Workers設定（D1・静的アセットのバインディング）
├── schema.sql          # D1のテーブル定義 + 初期学習タイプ（宿題/自学/通信）
├── src/index.js        # /api/* のAPIハンドラ（Workers本体）
└── public/
    ├── index.html      # 入力ページ
    ├── display.html    # 表示ページ
    ├── manifest-input.json
    ├── manifest-display.json
    ├── sw.js
    ├── css/style.css
    └── js/
        ├── input.js    # 学習記録・日記
        ├── tasks.js    # タスク管理・持ち物・固定学習ブロック・週次振り返り・集中モード
        └── display.js
```

## セットアップ

1. 依存関係のインストール（wrangler）
   ```
   npm install
   ```

2. Cloudflareにログイン
   ```
   npx wrangler login
   ```

3. D1データベースを作成
   ```
   npx wrangler d1 create study-tracker-db
   ```
   出力される `database_id` を `wrangler.toml` の
   `REPLACE_WITH_YOUR_DATABASE_ID` 部分に貼り付けてください。

4. スキーマを適用
   - ローカル動作確認用: `npm run db:init:local`
   - 本番用: `npm run db:init:remote`
   - 既存DBに対して再実行しても、新しく追加されたテーブル
     （`diary_entries` / `tasks` / `study_blocks` / `belongings` / `task_streak`）
     だけが安全に追加されます（`CREATE TABLE IF NOT EXISTS`）。

5. ローカルで確認
   ```
   npm run dev
   ```
   `http://localhost:8787/` が入力ページ、
   `http://localhost:8787/display.html` が表示ページです。

6. デプロイ
   ```
   npm run deploy
   ```

## 学習タイプについて

初期状態で「宿題」「自学」「通信」の3種類が登録されています（`schema.sql`）。
入力ページ下部の「学習タイプを編集する」から、名前と色を自由に追加・削除できます
（記録が残っているタイプは削除できません）。追加したタイプは表示ページの
カレンダーの色分け・凡例にも自動的に反映されます。

## 日記について

入力ページの「その日の日記」から、日付ごとに1件（上書き保存）で日記を記録できます。
表示ページの「今日の日記」に、今日書いた内容がそのままプレビュー表示されます。

## タスク管理について（task-managerから移植）

入力ページに以下の機能があります。

- **今日やること**：未完了タスクのうち、優先度スコア（種類の重要度 ÷ 締切までの残り日数。
  提出物 > 宿題 > 自由タスクの順、締切が近いほど・過ぎているほど優先度が上がる）が
  高い順に上位3件を表示します。前日から持ち越されたタスクは自動で「先延ばし回数」が
  加算されます。
- **集中モード**：「集中モードで進める」から、優先度が最も高いタスクだけを表示する
  全画面モードに入ります。完了すると自動で次のタスクに進み、3件完了するごとに
  「ひと息つこう」という小休止画面をはさみます。
- **持ち物チェック**：日付を指定して持ち物を登録し、チェックできます。その日の全項目に
  チェックが付くと達成ストリークが1日分加算されます。
- **固定学習ブロック**：曜日×時間帯で決まった学習時間を登録しておくと、その時間になった
  ときに「今日やること」欄にバナー通知が出ます（入力ページを開いている間のみ、
  30秒ごとにチェックします）。
- **週次振り返り**：過去7日間のタスク達成率・平均先延ばし回数・タスク達成ストリーク・
  種類別の完了数をまとめて表示します。
- タスク完了・持ち物全チェックで加算される「タスク達成ストリーク」は、学習記録の
  連続日数（表示ページのストリーク）とは別カウントです。

タスク管理・持ち物・固定学習ブロックは入力ページのみに実装しています
（表示ページは常時表示前提の1画面レイアウトのため、レイアウトを崩さないよう
今回は対象外にしています）。

## 表示ページの使い方

タブレットを横向きで壁や机に固定し、常時表示させる想定です。

- 左側：当月のカレンダー。学習した日には登録タイプの色ドットが付き、
  現在の連続記録（ストリーク）に含まれる日はオレンジの下線でつながって見えます。
- 右側：現在の連続日数、今日記録した学習の一覧・合計時間、今日の日記のプレビュー。
- 5分ごとに自動でデータを再取得するので、開きっぱなしでも最新の状態を保てます。
- カレンダーは「‹ ›」で前後の月に移動できます（今日の概要は常に「今日」を表示します）。
